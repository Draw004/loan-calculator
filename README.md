# Carrowmont Loan / EMI Calculator

Production source for the Carrowmont fixed-rate Loan / EMI Calculator at:

https://carrowmont.com/loan-calculator/

The calculator supports standard monthly amortization, reverse principal modelling from a monthly payment budget, optional fees, optional extra principal payments, amortization tables, CSV export and a downloadable planning report.

The tool is educational and does not provide lender eligibility, approval, settlement quotes or regulated APR disclosures.
